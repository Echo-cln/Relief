# Relief Desktop

把待办、日历和透明桌面清单放在一起，浏览器替你留意快到期的事。

**Relief Desktop 0.2.0 · Windows 10/11 x64**。桌面端与浏览器扩展各自安装，扩展需要 **Relief 1.4.0+**。当前提供解压运行版；应用尚未签名。

## 开始使用

### 免安装版

1. 将 `Relief-Desktop-Windows-0.2.0.zip` **完整解压**。
2. 打开解压文件夹中的 `Relief.exe`。不要只从 ZIP 中拖出一个 EXE；旁边的 DLL、resources 与 locales 目录也需要保留。
3. 在左侧打开“桌面清单”，显示可拖动、可从右下角缩放的透明小窗；标题栏的锁形图标可以冻结位置，日历图标切换待办 / 月历。小窗中可以连续按 Enter 快速新增待办，也可以双击日期格创建当天事项。
4. 从“偏好设置 → 桌面清单”调整置顶、锁定、鼠标穿透和背景透明度。

关闭主窗口默认留在系统托盘。托盘菜单可以重新打开、恢复清单点击、退出应用。`Ctrl + Alt + R` 可恢复鼠标穿透后无法点击的清单，并打开主窗口。退出整个应用后，本机提醒与浏览器联动均暂停，下次启动会补发未处理的时间提醒。

### 浏览器 DDL 提醒

1. 启动桌面应用，打开 **偏好设置 → 浏览器联动 → 复制配对码**。
2. 安装 / 更新 Relief 1.4.0 扩展并刷新已打开的网页。
3. 在浏览器扩展管理页打开 Relief 的“扩展程序选项”，展开 **桌面待办联动**，粘贴配对码并点击“连接”。
4. 为任务添加“时间提醒”。到点后，在当前活动且允许显示 Relief 的网页顶部显示一张小提醒；点击“完成”或“稍后 10 分钟”会写回桌面清单。

默认只在 ChatGPT 提醒；需要其他网页时，在扩展中开启“浏览器全页面陪伴”并授予权限。浏览器内部页面、扩展商店等不能注入。任务不会因为仅设置了截止日期就自动生成时间提醒，请在编辑面板明确添加提醒时间。关闭桌面联动开关可以停用接口。

桌面端运行时，未检测到浏览器轮询会尝试使用系统通知；浏览器连接活跃时优先交给浏览器提醒。系统勿扰、通知权限、浏览器休眠会影响到达时间。这是分钟级个人提醒工具，不承诺系统休眠或应用退出期间仍准时弹出。浏览器中的 DDL 提醒与喝水 / 休息提醒分别处理，不触发灰屏，也不叠在专注倒计时上。

## 当前功能

| 功能 | 支持 |
| --- | --- |
| 待办管理 | 新增、编辑、完成与划去、撤销完成、回收站、恢复、永久删除 |
| 任务信息 | 清单、优先级、标签、备注、子任务、截止日期与可选具体时刻 |
| 提醒 | 每项最多 12 个时间提醒，浏览器完成 / 稍后 / 本次不再提醒，系统通知 |
| 重复 | 每日、每周、每月，自定义间隔；保留完成历史 |
| 查找整理 | 关键词搜索、优先级筛选、截止 / 优先级排序、手动拖动排序 |
| 日历 | 月 / 周 / 日程视图，可切换截止事项与提醒时间；双击日期新建待办；内置 2025–2040 年常见农历与节日日期，可添加每年重复的纪念日 |
| 天气 | 日历页可按城市查询天气和温度；每 30 分钟自动更新，可手动刷新 |
| 桌面清单 | 半透明背景和透明度设置、置顶、可拖动 / 缩放、锁定、折叠；待办与月历小窗切换，与主窗口同步 |
| 外观 | 鼠尾草、燕麦、浅玫瑰、雾蓝、夜色、自定义颜色 |
| 数据 | 本地保存、最近 7 天备份、损坏恢复、JSON 导入 / 导出 |
| 快捷操作 | `Ctrl + N` 新建，`/` 搜索，`Ctrl + Alt + R` 恢复窗口 |

单机个人版，不包含多人协作、云同步、手机端、外部日历账户接入或自动更新。节日与节气由随应用打包的日期数据提供，个人纪念日保存在本机；没有把外部日历服务的日程同步进来。天气使用 Open‑Meteo 地理编码和数值预报接口，显示查询时间与数据来源；模型数值不是气象局站点的即时观测，官方气象服务接口通常需要自行申请密钥。透明度只改变清单背景，文字保持不透明；透明窗口的桌面模糊观感由系统合成器决定，不保证与每张壁纸相同。

## 数据与隐私

- Windows 默认数据目录：`%APPDATA%/relief-desktop/`。实际路径由 Electron `app.getPath('userData')` 决定。
- `tasks.json` 是任务和偏好；`backup-YYYY-MM-DD.json` 保留最近 7 天的快照；损坏文件另存为 `.corrupt-时间戳`。
- 任务通过串行事务、临时文件与原子替换写入；多窗口使用同一数据源。编辑期间若另一个窗口修改该任务，拒绝覆盖旧版本。
- 联动服务只监听 `127.0.0.1:43821`，采用随机配对码鉴权，拒绝普通网页 Origin。扩展后台连接本机，页面脚本只接收要显示的提醒，不接收配对码。
- 配对码是本机访问凭据，使用系统安全存储（系统不支持时使用本机受限文件），不要转发给他人。导出任务不会包含配对码。
- 没有云端任务服务器，不需要 AI API Key。不能把本机联动当作跨设备同步。

## 从源码运行与构建

需要 Node.js 24 LTS、npm 和完整仓库（复用根目录 `assets/mascot-mobile.png`）。

```bash
cd desktop
npm ci
npm start
```

Windows 中也可运行 `start.ps1`。构建安装版和单文件便携版：

```bash
npm test
npm run dist:win
```

产物位于 `desktop/release/`。仅打包可解压目录：`npm run pack:win`。Windows 安装程序应在 Windows 环境构建；Linux 交叉打包安装程序需要 Wine。仓库附有 Windows GitHub Actions 构建流程。

不启动 Electron 的浏览器预览：`npm run preview`，打开终端打印的本机地址。也可运行 `npm run build:preview` 生成单文件 HTML。预览支持本地编辑与持久化，但不冒充桌面托盘、系统置顶和真实扩展联动。
