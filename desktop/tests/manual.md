# Relief Desktop 0.2.0 人工验收

## Windows

1. 完整解压目录，运行 Relief.exe，确认图标、中文、7 项初始待办。
2. 添加一项含子任务、备注、日期、具体时刻与 1 分钟后提醒的任务，重启后确认保留。
3. 完成 / 撤销、删除 / 恢复、月周日程视图、搜索、手动排序分别检查。
4. 显示桌面清单，拖动；锁定后无法拖动；调整透明度时背景透明且文字清晰。
5. 折叠后窗口收起，展开恢复；任务勾选立即同步主窗口；编辑入口打开对应任务。
6. 鼠标穿透后使用托盘恢复点击；Ctrl + Alt + R 打开主窗口。
7. 关闭主窗口留在托盘，退出应用不留进程；开机启动开关需在 Windows 登录后检查。
8. 导出后修改任务，再导入导出文件；确认替换前有任务数量确认。

## 扩展联动

1. 加载扩展 1.4.0，打开扩展程序选项，粘贴桌面配对码，检查连接显示真实数量。
2. 启用全页面模式，在两个普通网页中停留，设置 1 分钟后提醒：只在当前活动页显示一次。
3. 点击完成：桌面任务进入已完成；稍后：10 分钟内不出现，之后再次提醒。
4. 点叉只处理本次提醒，不完成任务；桌面查看打开对应任务。
5. 喝水 / 休息灰屏倒计时期间不叠加 DDL 卡片，结束后轮询再展示。
6. 关闭桌面应用、输入错误配对码、占用 43821 端口、关闭桌面联动开关，均应提示失败，不报成功。
7. 浏览器退出或系统休眠期间不承诺弹窗；恢复后补发未处理事项。
8. 在启用范围外 / 隐藏陪伴形象时不发送页面弹窗。检查扩展存储迁移不影响原有喝水与休息偏好。

## 当前已跑检查

Node 模型 / 存储 / HTTP / 扩展后台测试；本地 Chromium 页面操作；Windows 包内文件与主入口检查。此清单的 Windows 人工项目没有在当前 Linux 环境中标记通过。

## Relief Desktop 0.2.0 新增验收

1. 在主窗口检查导航分组标题、字号和任务字号层级；完成任务应在标题上显示中划线，并能从“已完成”页恢复。
2. 打开任务编辑器，确认对话框位于页面中央。新建分类并反复创建分类，侧栏颜色按六色循环。
3. 打开“桌面清单”，从右下角拖动缩放；拖动标题栏移动；点击锁形图标后两者都应冻结，再次点击后恢复。
4. 通过透明度滑块调整背景，确认桌面壁纸可透出且任务文字保持清晰；在小窗里完成一项，确认“未完成 / 已完成”计数及划线更新。
5. 在小窗快速添加中连续按 Enter 添加多条，再打开“日历”小窗；双击日期格，新待办的日期应为该日期。
6. 在主窗口切换月 / 周 / 日程；双击月份日期格新建待办；验证元旦、春节、清明、端午、中秋等内置节日与“万圣节”等公历标签。
7. 添加年度纪念日，确认日期格与日程页出现；改到下一年验证再次出现；删除后确认消失。
8. 日历天气输入城市并查询，检查城市、温度、数据来源和查询时间；手动刷新及 30 分钟自动刷新都应更新数据。
