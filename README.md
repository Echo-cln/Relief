# Relief

在浏览器里陪你喝水、休息，也用桌面清单和日历，替你记住快到期的事。

**浏览器扩展 1.4.0 · Relief Desktop 0.2.0**

## Relief Desktop

Windows 桌面应用支持桌面日历与透明待办小窗、拖动缩放、节日 / 纪念日、城市天气、快速换行新增与自定义配色。已录入截图中可见的 7 项 DDL，截止日期与铃铛提醒分别保存。

详见 [桌面端 README](desktop/README.md) 和 [首次使用验收清单](desktop/tests/manual.md)。

### 桌面与浏览器联动

启动桌面应用 → 偏好设置 → 浏览器联动 → 复制配对码；在 Relief 扩展程序选项中展开“桌面待办联动”，粘贴并连接。

时间到达时，在当前活动且允许显示 Relief 的网页顶部弹出一张简洁 DDL 卡片。可以完成、稍后 10 分钟、本次不再提醒或打开桌面详情；完成与稍后操作会写回同一份桌面数据。多个标签页共用分发记录，专注提醒期间不叠加 DDL 卡片。默认仍只在 ChatGPT 显示，需要其他网页时开启全页面模式。

联动仅访问本机 `127.0.0.1:43821`，需桌面应用后台运行，扩展新增 `alarms` 权限和本机地址权限。配对码不传给网页脚本，不上传任务到云端。提醒为分钟级，应用退出、系统休眠、浏览器内部页面不能保证到点弹出。

## 浏览器陪伴扩展

默认在 **ChatGPT** 显示，可选择开启普通网页陪伴。提供可拖动的手绘形象、居中提醒卡和固定 ChatGPT 会话快速输入框，无需独立 AI API 或 API Key。支持 Chrome / Edge 等 Chromium 102+ 浏览器。

## 功能

### 两种显示范围，一个开关

| 范围 | 行为 |
| --- | --- |
| 仅 ChatGPT（默认） | 在 `chatgpt.com` 与旧版 `chat.openai.com` 显示 |
| 浏览器全页面陪伴 | 授权后，在普通 HTTP / HTTPS 网页显示；新打开的页面自动加载 |

1. 点击浏览器工具栏中的 Relief 图标。
2. 打开“浏览器全页面陪伴”开关，接受浏览器的可选站点访问授权。
3. 点击“显示陪伴形象”，恢复已打开且允许注入的网页中的形象；后续打开普通网页也会自动显示。

也可在设置 → 形象 → 显示范围入口打开扩展设置页修改。授权被拒绝时保持 ChatGPT 模式；关闭开关后移除其他网页的形象、停止未来注入，并尝试撤回可选站点权限。重启浏览器后保留范围选择，授权撤回时自动恢复 ChatGPT 模式。

浏览器设置页、内置新标签页、扩展商店、其他扩展页面、本地文件与部分内置 PDF 阅读器等不支持注入；组织策略或个别网页安全限制也可能阻止显示。全页面模式是同一个形象在各网页中显示，不是浏览器地址栏之上或系统桌面上的悬浮窗。


### 喝水与休息，各自设置

| 设置 | 默认值 | 范围 |
| --- | --- | --- |
| 喝水提醒间隔 | 45 分钟 | 1–240 分钟 |
| 休息提醒间隔 | 50 分钟 | 1–240 分钟 |
| 喝水专注时长 | 5 秒 | 1–600 秒 |
| 休息专注时长 | 10 秒 | 1–600 秒 |
| 稍后提醒 | 10 分钟 | 1–120 分钟 |

- 喝水和休息始终分别提醒，没有合并选项。都到期时依次处理，两次提醒间至少留出 20 秒。
- 开启专注提醒后，页面变暗，卡片固定在页面正中央；倒计时结束后出现完成按钮。不显示关闭叉，保留“稍后”。
- 两个专注时长分别输入秒数，不用预设下拉选项；关闭专注模式后不显示秒数输入行。
- 可等待 ChatGPT 回答结束后再提醒；最多延后 60 秒。
- 可输入暂停分钟数，暂停到期自动恢复，也可提前继续。

### 当天计时与提醒进度

- 按浏览器本地日期在零点清零。当天累计、各自提醒进度、稍后状态、完成次数均保存在浏览器本地。
- 刷新页面后继续累计，不会把当天总时长当作刚到期的提醒。
- 只在当前显示范围内的标签页可见、文档有焦点且最近 60 秒有操作时累计；离开页面或长时间无操作后暂停。
- 后台统一处理标签页心跳，同一秒最多累计一次；同一个提醒只交给一个标签页显示。
- 设置底部显示今日陪伴时间和喝水、休息的确认次数。次数仅代表点击了完成，不代表实际饮水量。

### 形象与交互

- 支持吴星星和苏圈圈、小太阳、星星、云朵、月亮，以及 blingbling。
- blingbling：星星喝水、月亮休息、云朵设置；吴星星喝水、苏圈圈休息。
- 点击有轻微按压反馈；按住任一触控区域移动可拖动，拖动结束不会触发喝水或休息。
- 计时和设置共用形象下方的小工具条；形象下不再显示名称。
- 支持本次标签页会话、1 小时、今天、直到手动恢复四种隐藏方式。刷新仍属同一次标签页会话；关闭后重新打开恢复会话隐藏。
- 浅色与深色样式、减少动态效果偏好、窗口边界约束。

### 随手问一句

- 点击计时打开形象下方的小输入框，发送按钮与输入框处于同一行。
- Enter 发送，Shift + Enter 换行；中文输入法确认候选词时不会发送。
- 在目标会话中打开设置，点击“设为当前会话”；也可展开“编辑会话”输入名称和链接。
- 初始目标沿用本项目原有的“每日傻瓜QA”会话；其他使用者需改为自己有权限访问的会话。
- 在普通网页也可使用快速提问；仍复用 ChatGPT 目标标签页或打开指定会话，等待页面就绪后填写输入框并触发提交。不会新建聊天。
- 检查本次新增的用户消息，确认进入会话后才报告成功；不把已有的生成状态当作本次发送成功。
- 草稿自动保存在本地。发送失败保留原文；提交结果不明时阻止自动重复提交，需先查看目标会话。
- 目标会话已有草稿时停止发送，不覆盖原文。

## 安装与更新

本项目使用 Chromium 浏览器开发者模式加载。ZIP 不是可双击运行的安装程序。

1. 下载并解压安装包，或下载 GitHub 仓库源码。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
3. 开启开发者模式，选择“加载已解压的扩展”，选中包含 `manifest.json` 的目录。
4. 打开或刷新 ChatGPT 页面，并允许 Relief 访问该站点。
5. 可将 Relief 固定在浏览器工具栏，点击“显示陪伴形象”或“提醒设置”。

**更新推荐覆盖原来加载的目录，再在扩展管理页点击重新加载，最后刷新 ChatGPT。** 这样保留原扩展的本地设置和计时。卸载重装可能清除这些数据。不要同时加载多个 Relief 副本。

## 使用入口

| 操作 | 入口 |
| --- | --- |
| 开关全页面陪伴 | 浏览器工具栏 Relief → 浏览器全页面陪伴；或备用设置页 → 形象 |
| 修改提醒间隔、两个专注秒数、稍后时间 | 形象下方齿轮 → 提醒 |
| 暂停提醒或更换快捷会话 | 提醒设置 |
| 更换、隐藏形象或恢复位置 | 提醒设置 → 形象 |
| 找回已隐藏形象 | 浏览器工具栏 Relief → 显示陪伴形象 |
| 页面组件未连接时修改设置 | 工具栏 → 提醒设置，自动打开扩展备用设置页 |
| 打开备用设置页 | 扩展管理页 → Relief → 扩展程序选项 |

设置即时保存。卡片不附带第二张大插画；挂饰位于卡片上层。

## 故障排查

- **更新后仍显示旧界面：** 检查扩展版本和已加载的目录；覆盖文件后重新加载扩展，再刷新所有要使用的 ChatGPT 标签页。
- **找不到形象：** 点击工具栏的显示按钮。新版会恢复宿主，检查布局和屏幕边界，位置异常时恢复默认位置。
- **设置打不开：** 工具栏的提醒设置会退回扩展自己的设置页，不要求页面组件正常。
- **消息没有发送：** 查看输入框下方错误，确认目标链接、登录和会话访问权限；检查目标页面的草稿或正在生成的回答。
- **显示提交结果不明：** 先查看目标会话，避免重复点击发送；如确需新发，可重新编辑问题后提交。

## 权限与本地数据

- 默认必需站点权限为 `chatgpt.com`、`chat.openai.com` 和桌面联动使用的 `http://127.0.0.1/*`。全页面陪伴使用可选 HTTP / HTTPS 站点权限，只有主动打开开关并接受浏览器授权后才注册全页面脚本。
- `alarms` 每分钟检查已配对桌面的时间提醒；`storage` 保存设置、计时、提醒状态、本地问题草稿和短期提交状态；`activeTab` 与 `scripting` 用于工具栏操作和恢复页面组件。
- 普通网页模式只使用交互时间和页面焦点来计时，不保存浏览记录、网页地址或正文。扩展不调用独立 AI 服务，不上传计时、宠物设置或统计。主动提交的问题通过 ChatGPT 页面自己的输入框发送，适用 ChatGPT 的服务规则。
- 确认发送时会短暂检查目标页新出现的用户消息，不保存已有对话内容。提交状态只保存请求标识、状态和时间；草稿保存你未成功提交的问题文本。
- 页面组件置于 Shadow DOM 中，不修改宿主网页原有布局；仅注入顶层页面，避免嵌套框架重复出现。普通网页中的“等回答结束再提醒”不会检查网页正文，只在 ChatGPT 页面识别正在生成的状态。发送功能使用网页 DOM，ChatGPT 更新页面后仍可能需要适配。
- 卸载扩展可清除本扩展的本地数据。

## 开发与验证

无构建步骤。直接修改源文件，在扩展管理页重新加载。

```text
Relief/
├── assets/                 # 原有手绘插画与宠物资源
├── config.js               # 共享默认值、字段范围、会话链接校验
├── scope.js                # 工具栏与扩展设置页的可选授权开关
├── scope-manager.js        # 后台管理全页面脚本注册、恢复与移除
├── state.js                # 可测试的计时和独立提醒状态转换
├── background.js           # 串行状态管理、多标签协调、提交路由
├── content.js              # 页面界面、输入、拖动、提醒卡与设置
├── settings.html           # 复用设置组件的备用入口
├── popup.html / popup.js    # 工具栏入口与恢复操作
├── manifest.json
└── tests/                  # Node 内置测试与手动验收说明
```

```bash
node --test tests/*.test.cjs
node --check content.js
node --check background.js
```

自动测试覆盖可选权限拒绝、范围开关、已有网页注入、权限撤回、跨网页恢复形象，以及多标签去重、刷新续计、日切、两个独立提醒、稍后、暂停、回答延后、待处理提醒转移、秒数边界和提交去重。实际登录 ChatGPT 的发送、页面视觉与扩展兼容性需要浏览器验收；自动逻辑测试不等于这些流程已实测。见 [手动验收清单](tests/manual.md)。
