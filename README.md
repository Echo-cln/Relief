# Relief

Relief 是一款运行在 ChatGPT 网页中的轻量浏览器扩展，提供喝水与休息提醒，并可在页面角落显示可拖动的陪伴形象。

> 目前支持 ChatGPT（`chatgpt.com` 与旧版 `chat.openai.com`）。

## 功能

- 自定义喝水、休息和稍后提醒的时间间隔。
- 显示可拖动的陪伴形象；支持吴星星与苏圈圈、单个插画和 blingbling 挂饰。
- 星星触发喝水提醒，月亮触发休息提醒，云朵打开设置。
- 可按本次会话、1 小时、今天或手动恢复来隐藏形象。
- 专注提醒默认开启：喝水提醒页面变暗 5 秒，休息提醒变暗 10 秒，之后可确认完成；可在设置中关闭专注模式，或选择稍后提醒。
- 页面右下角采用“形象在上、活跃计时与设置并排在下”的紧凑布局；提醒卡固定在页面正中央，不跟随形象移动；卡片不再叠放第二张宠物插画，形象位于卡片上层。
- 点击右下角活跃计时，可在形象下方打开小型快速输入框，发送按钮位于输入框右侧；消息会提交到 Daily 项目下固定的“每日傻瓜QA”会话，不会新建会话。
- 点击 blingbling 的星星、月亮或云朵时会有按压高亮与轻弹反馈，分别对应喝水、休息和设置。
- 计时按浏览器本地日期每天清零；当天累计值保存在浏览器本地，刷新页面后继续累计。计时仅在 ChatGPT 页面处于前台且近期有操作时累计；切到后台或 60 秒无操作后暂停。
- 工具栏菜单可重新显示形象或打开提醒设置；若页面尚未连接，扩展会在按钮操作时尝试启动页面脚本。
- 工具栏菜单会核对页面脚本版本和界面实际可见状态；显示命令会等待页面布局完成并重试，未确认显示时会给出重新加载提示。

## 安装

本项目目前以浏览器开发者模式加载，不是双击运行的安装程序。

1. 下载并解压 ZIP 安装包。
2. 打开浏览器扩展管理页：Chrome 使用 `chrome://extensions`，Edge 使用 `edge://extensions`。
3. 开启“开发者模式”或“开发人员模式”。
4. 选择“加载已解压的扩展”，并选中刚解压、包含 `manifest.json` 的项目文件夹（GitHub 下载包的目录名通常带有分支名）。
5. 打开或刷新 ChatGPT 页面，并在浏览器询问时允许 Relief 访问该页面。
6. 可将 Relief 固定到工具栏。点击图标后可显示陪伴形象或打开提醒设置。

## 使用

- 在设置中调整喝水、休息和稍后提醒的分钟数。
- 选择陪伴形象并设置隐藏时长；隐藏后可从工具栏点击“显示陪伴形象”恢复。
- 点击吴星星触发喝水提醒，点击苏圈圈触发休息提醒。
- 选择 blingbling 后，点击星星喝水、月亮休息、云朵打开设置。
- 点击计时按钮输入问题，按 Enter 或输入框右侧的“发送”按钮提交到“每日傻瓜QA”；Shift + Enter 可换行。发送过程会等待目标会话和输入框载入，提交后会检查消息是否进入对话；若无法确认，界面会提示检查会话，避免误报成功。
- 如果目标对话中已经有未发送的草稿，Relief 会停止发送并提示你先处理草稿，避免覆盖内容。
- 专注提醒默认开启并应用于每次喝水和休息提醒：喝水等待 5 秒，休息等待 10 秒；倒计时期间不显示关闭叉号，完成按钮出现后可确认，也可选择“稍后”。

## 权限与隐私

- 页面匹配范围仅为 `chatgpt.com` 和 `chat.openai.com`。
- `storage` 用于在本地保存设置；`scripting` 用于响应工具栏操作并在当前 ChatGPT 标签页启动扩展脚本；ChatGPT 主机权限用于定位目标会话并通过页面脚本发送你在快速输入框中提交的内容。
- 提醒偏好保存在浏览器本地。扩展不调用独立 AI 接口；快速聊天会通过 ChatGPT 页面自身的输入框提交消息。
- 扩展不读取或保存已有对话内容，不调用 AI 接口；只有你主动提交的快速输入内容会被发送到指定的 ChatGPT 会话，并由 ChatGPT 按其服务规则处理。
- 页面界面放在 Shadow DOM 中，减少样式对 ChatGPT 页面及其他扩展的影响。

## 故障排查

1. 安装或更新后，先刷新 ChatGPT 页面。
2. 在扩展管理页确认 Relief 已启用，并允许其访问 ChatGPT。
3. 点击工具栏图标，再选择“显示陪伴形象”或“提醒设置”。
4. 更新扩展文件后，在扩展管理页点击“重新加载”，然后刷新 ChatGPT。
5. 若 Relief 菜单提示当前页面尚未加载最新脚本，刷新当前 ChatGPT 标签页后再试。扩展更新后，已打开的页面需要重新加载才能使用新版界面。

## 开发

项目为 Manifest V3 浏览器扩展，无构建步骤。修改后可在扩展管理页重新加载扩展，并刷新 ChatGPT 验证。

目录结构：

```text
Relief/
├── assets/       # 陪伴形象与插画资源
│   ├── pet-pair-avatar.png # 吴星星和苏圈圈提醒卡头像
│   └── mascot-mobile.png   # blingbling 挂饰
├── content.js    # 页面组件、提醒与设置交互
├── background.js # 固定会话标签页定位与快速消息路由
├── popup.html    # 工具栏弹窗
├── popup.js      # 工具栏操作与页面连接
├── manifest.json # 扩展配置与权限
└── README.md
```
